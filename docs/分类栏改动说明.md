# 应用面板分类栏改动说明（v0.9.20.16）

## 需求
> 不是移除底部的分类行，只是不需要「全部」这一个分类。

底部分类标签行**保留**，只把「全部」从标签行里去掉；默认仍然显示全部内容。

## 改动
唯一改动文件：`source/src/IconBox/BoardWindow.cs`

| 位置 | 改动 |
| --- | --- |
| `BoardWindow.cs:1014-1021` | `BuildCategoryBar()` 的循环开头跳过 `id == "all"`，其余分类标签照旧生成在底部第 6 行 |
| `BoardWindow.cs:161-162` | 新增字段 `allCategoryButton` / 「全部」不再做成标签的注释 |
| `BoardWindow.cs:953-961` | 分页栏最左侧新增「显示全部」按钮，默认 `Collapsed` |
| `BoardWindow.cs:1297-1305` | `UpdateAllCategoryButton()`：只在离开「全部」视图时露出按钮 |
| `BoardWindow.cs:1338-1339` | `SetCategory()` 再次点击「显示全部」时只同步按钮可见性 |
| `BoardWindow.cs:538` | `ReleaseHiddenView()` 释放新字段 |

## 交互
- 默认视图仍是「全部」，与改动前一致，但底部不再有「全部」标签。
- 鼠标悬停任意分类标签即切入该分类（原行为）。
- 进入任意分类后，分页栏左侧出现「显示全部」，点击回到全部视图。
- 分类的拖动排序、右键重命名/新建/删除、拖图标归类全部保持原样。

## 追加需求：分类行居中（m06419）
> 分类行要居中。

标签不再从左侧起排，整行居中。

| 位置 | 改动 |
| --- | --- |
| BoardWindow.cs:56-58 | 新增字段 categoryRow（分类行宿主 Grid） |
| BoardWindow.cs:872-880 | categoryRow 铺满第 6 行；categoryBar 设 HorizontalAlignment=Center 并挂到它下面 |
| BoardWindow.cs:542 | ReleaseHiddenView() 释放 categoryRow |
| BuildCategoryBar() 末尾 | categoryRow 也挂 AllowDrop/DragOver/Drop，空白处拖放落到整行而不只是标签带 |
| 新增 CategoryDropToEnd() | 抽出「拖到空白处 = 移到最末」逻辑，两个落点共用 |

拖动位置仍相对 categoryBar 计算，标签左右留白不影响拖动排序的手感。
