## 1. 术语（对齐一下，避免歧义）

**Dock 的三种工作模式**（设置里 Dock DIY 页的三个开关组合）

| 代号            | 开关状态                | 现在的行为概述                                                             |
| ------------- | ------------------- | ------------------------------------------------------------------- |
| **M1 跟随任务栏**  | 「跟随任务栏自动隐藏」= 开      | Dock 只在任务栏露出时出现；任务栏收起时 Dock 沉到屏幕外；鼠标压屏幕最底 1~2 px 时任务栏会先弹出，Dock 随后出现 |
| **M2 悬停自动隐藏** | 「Dock 自动隐藏」= 开（跟随关） | 鼠标进入底边区域才出现，移开 `HideDelay`（默认 900 ms）后收起                            |
| **M3 常驻**     | 两个开关都关              | Dock 一直显示在底部，不藏                                                     |

**Windows 任务栏的三种状态**（设置里「任务栏」相关项）

| 代号          | 含义                                   |
| ----------- | ------------------------------------ |
| **T1 常显**   | 任务栏一直在底部，不自动隐藏                       |
| **T2 自动隐藏** | 任务栏平时收起，鼠标压到屏幕最底边才弹出（Windows 自己的行为）  |
| **T3 彻底隐藏** | 本软件把任务栏整个藏起来（连压底边也不弹出来），通常配合 Dock 使用 |

**三个「界面」层级**，后面问题里会反复用到：

1. **桌面**（所有窗口最小化、或按 Win+D 之后）
2. **普通窗口**（有边框、没最大化、没全屏）
3. **最大化窗口**（标题栏顶到屏幕顶，底边压到屏幕最底，Win11 里底边会被任务栏覆盖）
4. **真全屏**（游戏、视频播放器、浏览器 F11，把整个屏幕占满且自己画满）

## 2. 当前实现速查（1.0.23 的代码事实，供你对照）

| #  | 规则                   | 当前实现                                                       | 位置                             |
| -- | -------------------- | ---------------------------------------------------------- | ------------------------------ |
| 1  | 跟随任务栏的显示条件           | 任务栏可见高度 `taskbarDip > 4 DIP`                               | `DockWindow.cs:1472` 起         |
| 2  | 任务栏收起后的「保持时间」        | 鼠标一旦离开判定区，**1.2 s** 后收起它                                   | `DockWindow.cs:1549`           |
| 3  | 悬停模式的收起延迟            | `HideDelay`，默认 **900 ms**，可调 200~3000                      | `DockOptions.HideDelay`        |
| 4  | 判定「鼠标在 Dock 上」       | Dock 落位矩形外扩 **8 DIP**；跟随模式下再叠加实时窗口矩形 ±24 px                | `CursorOverDock():1048`        |
| 5  | 唤出触发带（M1/T3 或任务栏未弹时） | 屏幕最底 **6~48 DIP**（取 `EdgeRange`，默认 12 → 实际 12）             | `DockWindow.cs:1506`           |
| 6  | 唤出触发带（任务栏常显 / 桌面）    | 距底 `max(EdgeRange, Dock 高度)` ≈ **132 DIP** 的高带             | `DockWindow.cs` nearBottom     |
| 7  | 桌面常驻                 | 前台是桌面（`Progman`/`WorkerW`）或 Dock 落位区上空着 → Dock 常显          | `desktopFront` / `areaFree`    |
| 8  | 全屏抑制                 | 判为真全屏 → Dock 直接隐藏；但「任务栏可见」或「鼠标压最底边」时放行                     | `SuppressionOverridden():1375` |
| 9  | 置顶（压住别的窗口）           | 只有「鼠标在底边带 / 鼠标在 Dock 上 / 任务栏可见 / 用户勾了始终置顶 / 设置窗口打开」时才置顶    | `ApplyZOrder(...)`             |
| 10 | 浮层（控制中心 / 运行列表）      | 打开期间 Dock 必须保持显示；鼠标离开浮层与 Dock **900 ms** 后，浮层与 Dock 一起收起   | `UpdateOverlayAutoClose()`     |
| 11 | 点击 Dock              | 不抢前台焦点（`MA_NOACTIVATE`），点图标才把目标窗口切到前台                      | `DockWindow.cs:658`            |
| 12 | Dock 高度 / 位置         | 高 132 px（150% 缩放下 = 88 DIP）、水平居中、距任务栏 `DockGap`（默认 12 DIP） | `DockOptions`                  |

⚠ 已知的两处「口径不一致」，很可能就是你觉得不对的地方：

- **第 5 与第 6 条不对称**：任务栏常显时，鼠标离屏幕底 100 px 就会把 Dock 唤出来；而任务栏自动隐藏/彻底隐藏时，必须压到最底 1~2 px 才有反应。
- **第 7 条「桌面常驻」没有出口**：只要前台是桌面，Dock 就一直显示，哪怕你在桌面上拖选图标、看桌面壁纸。

## 4. 唤出（Dock 什么时候出现）

**Q4.1** 触发区的**横向范围**：鼠标在屏幕底部，但横向离 Dock 很远（比如 Dock 居中只占中间 1047 px，你把鼠标放在屏幕最左边）——  
　A) 也会出现　B) 不出现，必须在 Dock 的横向范围内　C) 左右各放宽半个屏幕　答：只要唤出任务栏dock栏就要出现

**Q4.2** T2 自动隐藏时，鼠标从下往上移动，**先碰到任务栏**还是先碰到 Dock？  
　A) 任务栏先弹，Dock 等任务栏出来了再出现（现在是这样）　B) Dock 直接出现，不等任务栏　C) 两个同时　答：A

**Q4.3** ⚠ T2 自动隐藏时，「鼠标压到最底边」这个动作，你希望 Dock 出现的速度是：  
　A) 任务栏弹出后立刻（≤100 ms）　B) 允许 200~300 ms 的余量　C) 必须跟任务栏同一帧出现　答：C

**Q4.4** T1 常显时，鼠标离屏幕底 **100 px**（没压到 Dock 上）就触发 Dock 出现，是否合理？  
　A) 合理（现在是 132 DIP 的高带）　B) 太灵敏，应缩到 20~40 px　C) 只在鼠标压到 Dock 高度内才出现　答：B

**Q4.5** 「鼠标从屏幕中部快速向下扫到底边（0.1 s 内划过去）」——你希望：  
　A) 出现（只要碰到触发带）　B) 不出现（需要停留 ≥100 ms）　答：A

**Q4.6** Dock 与任务栏之间有一条 `DockGap`（默认 12 DIP）的空隙，鼠标停在这条缝隙里算不算「在 Dock 上」？  
　A) 算（不收起）　B) 不算（1.2 s 后收起）　答：A

**Q4.7** 任务栏被放在**屏幕左侧 / 顶部**时（不是底部），Dock 怎么办？  
　A) 仍然只在屏幕底部工作　B) 跟着任务栏走边　C) 隐藏 Dock　答：B

**Q4.8** ⚠ 同时满足「桌面在前台」和「任务栏自动隐藏」时，Dock 是否应该常驻？  
　A) 常驻（现在是这样）　B) 只在底边唤出　C) 常驻，但鼠标一离开 3 秒后收起　答：A

**Q4.9** Dock 出现时是否要**把正在播放的视频/画面上推**（像任务栏那样改变工作区）？  
　A) 不需要，覆盖即可　B) 需要，窗口应避让　答：B

**Q4.10** 开机后第一次把鼠标移到底边，只要 Dock 出现即可，还是要求「必须在 1 秒内出现」？  
　答：不要求速度，只需要和任务栏出现消失保持一致即可

## 5. 收起（Dock 什么时候消失）

**Q5.1** 鼠标离开 Dock 后，多久收起？  
　当前：M1 是 1.2 s；M2 是 `HideDelay` 900 ms；浮层场景 900 ms。  
　希望统一成：900 ms（或写「按模式不同：M1 \__ ms / M2 \__ ms」）

**Q5.2** ⚠ 鼠标从 Dock **向下移到任务栏**（任务栏是常显的，就在 Dock 下面），应该收起吗？  
　A) 收起（离开 Dock 就算）　B) 不收起（因为还在屏幕底部区域）　答：B

**Q5.3** Dock 上有浮层打开时（控制中心、运行列表、右键菜单、窗口预览）：  
　A) 浮层开着就一直显示，浮层关了才开始计时（现在是这样）　B) 依然按 1.2 s 收起　答：A

**Q5.4** 从 Dock 移到浮层（控制中心）上，中途要经过桌面 —— 这个「路过」的时间（约 200~400 ms）够不够，会不会被误判成离开？  
　A) 够　B) 不够，需要更宽容（比如 600 ms 内回来都算没走）　答：B,700ms

**Q5.5** 打开**启动台面板**或**设置窗口**期间，Dock 是否必须常显？  
　A) 是（现在是）　B) 不必，跟着原来的规则走　答：A

**Q5.6** 鼠标停在 Dock 上不动，同时任务栏自己收起了 —— Dock 应该：  
　A) 保持在原位不动　B) 跟着任务栏下沉　答：A

**Q5.7** 收起动画的形态：  
　A) 整条滑到屏幕外（现在是这样）　B) 淡出 + 略微缩小　C) 瞬间消失　答：A

**Q5.8** 收起时，如果鼠标已经压在 Dock 的**下边缘**（最后 8 px），算不算「还在 Dock 上」？  
　答：算

## 15. 附：我在整理这份文档时发现的、**确定和你的历史要求不一致**的 5 处

这几条我已标 ⚠，但单独列出来，方便你重点确认：

1. **唤出带不对称**（Q4.2 / Q4.4）：T1 常显时 132 DIP 就能唤出，T2/T3 时必须压最底 1~2 px。
2. **桌面常驻没有出口**（Q4.8）：只要前台是桌面，Dock 就永不收起，哪怕你在桌面上做别的事。
3. **任务栏卡住时会连累 Dock**（Q8.2）：系统任务栏自动隐藏偶发失效时，Dock 会跟着一直不出现（你之前遇到过「要关掉再打开自动隐藏才恢复」）。
4. **全屏判定把「最大化 + 任务栏自动隐藏」判成全屏**（Q7.3）：已通过 `SuppressionOverridden()` 放行，但只在「任务栏已露出」时放行；如果任务栏还没来得及露出，Dock 依然不出现 —— 这可能是你说的「还是有很多情况不符合要求」之一。
5. **浮层与 Dock 的收起计时是两套**（Q5.3）：浮层空白处移开 900 ms 会连 Dock 一起收；但鼠标只在 Dock 上晃过、没进入浮层时，用的是 1.2 s —— 两个时间不一致。
