IconBox 最终用户许可与使用说明
=====================================

一、软件性质
IconBox（以下简称"本软件"）是一个免费的 Windows 桌面启动台，提供毛玻璃 Dock 栏、
应用面板（启动台）、控制中心（WiFi / 蓝牙 / 音量 / 亮度）和桌面组件（时钟、音乐）。
本软件为免费公益项目，不收费、不含广告、不收集任何个人数据，所有配置与数据都只保存在
本机的用户配置目录（%LOCALAPPDATA%\IconBox）中，卸载时可选择保留或一并删除。

二、允许的使用方式
1. 你可以自由地在自己的电脑上安装、使用本软件。
2. 你可以自由地分发本安装程序的原样副本。
3. 你可以获取并修改源代码，用于学习或个人定制。
   （源码与更新：https://github.com/llm147369/IconBox-Source）

三、免责声明
本软件按"现状"提供，不附带任何明示或暗示的担保。作者不对因使用本软件造成的任何直接或
间接损失承担责任。本软件会调整桌面图标显示、任务栏自动隐藏等系统外观设置，这些设置均可
在软件内恢复（设置 → 通用），卸载前也会自动还原，但仍请你理解并自行承担相关风险。

四、隐私
本软件不上传、不回传任何数据；网络仅用于你主动点击"检查更新"时访问 GitHub，
以及天气组件按需请求公开天气接口。

五、第三方组件
本软件包含或依赖以下第三方组件，其许可条款随安装目录一并提供：

  · NPSMLib.dll —— 系统媒体会话（GSMTC）补充通道
    许可：见 licenses\NPSMLib_LICENSE.txt
  · now-playing-service —— 音乐信息读取
    许可：见 licenses\now-playing-service_LICENSE.txt
  · Interop.UIAutomationClient.dll —— UI 自动化互操作（MIT）
  · Microsoft.Windows.SDK.Contracts / .NET Framework 4.8 运行时引用（微软许可）

完整的第三方声明见安装目录下的 THIRD_PARTY_NOTICES.md。

六、系统要求
  · Windows 10（1809 及以上）或 Windows 11，64 位或 32 位
  · .NET Framework 4.8（Windows 10 1903 及以上、Windows 11 已自带）
